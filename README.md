# Mercanti del Regno

Web app statica in HTML/CSS/JavaScript, progettata per essere pubblicata su GitHub Pages.

## Funzionalità incluse
- 60 città distribuite in 8 regioni geografiche.
- 48 merci con qualità 0–10, prezzi locali dinamici e tipologia deperibile/non deperibile.
- Stagioni, scorrimento a turni e decadimento delle merci deperibili.
- Mappa 2D visiva, città selezionabili e viaggi giorno per giorno.
- Cliccando una città sulla mappa si apre il listino completo del momento: acquisto, vendita, qualità e disponibilità di ogni merce.
- Eventi casuali durante il viaggio: assalti e meteo.
- Carovana con capacità, velocità e potenziamenti.
- Dipendenti con salari e bonus.
- Prestiti bancari e investimenti con rendimento periodico.
- Salvataggio automatico in localStorage.
- Esportazione/importazione del salvataggio in JSON.
- Nessun backend: funziona anche offline dopo il primo caricamento.

## Pubblicazione
Caricare tutti i file del repository GitHub, poi attivare **Settings → Pages → Deploy from branch → main / root**.
